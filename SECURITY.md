# Security policy

Please **do not open a public issue** for a vulnerability. Report it privately through GitHub's "Report a vulnerability" button (Security tab of this repository), or by email to security@imstillmine.com.

We are especially interested in:
- any way a selfie or face template could leave the user's browser in `site/`;
- any way the API could keep an image, an email address or an IP address longer than described in `docs/API.md`;
- ways to bypass the liveness check in tool 1.

Please give us a reasonable time to fix an issue before you disclose it publicly.
